## 一、产品定位

**一句话描述**：零安装、完全离线、高质量的 Markdown 转 PDF Web 工具。

**核心价值主张**：
- 打开浏览器即用，无需安装任何软件
- 所有处理在本地完成，文件不离开用户设备
- 预览即所得——屏幕上看到的就是导出 PDF 的样子
- 中文字体开箱即用，无需手动配置

**与竞品的核心差异**：

```
                 我们的定位
                   ★
    ┌──────────────────────────────┐
    │  零安装  ×  功能强  ×  离线  │
    └──────────────────────────────┘
    Dillinger/StackEdit：零安装但功能弱
    Typora/VS Code：功能强但需安装
    md-to-pdf/Pandoc：功能强但需命令行
```

## 二、技术架构

```
┌─────────────────────────────────────────────────┐
│                   Vite 6 + React 19              │
├──────────┬──────────┬──────────┬────────────────┤
│ 编辑器    │ 预览区    │ 设置面板  │ 工具栏          │
│ CM6      │ remark   │ 页面设置  │ 上传/导出/主题   │
│ GFM模式   │ rehype   │ 主题选择  │                │
│          │ KaTeX    │ 自定义CSS │                │

└─────────────────────────────────────────────────┘
```

## 三、功能需求（V1.0）

### 3.1 编辑器

| 功能 | 描述 | 优先级 |
|------|------|--------|
| Markdown 编辑 | CodeMirror 6 编辑器，GFM 语法模式 | M |
| 实时预览 | 编辑区与预览区同步滚动 | M |
| 拖拽上传 | 拖拽 .md 文件到编辑区自动加载 | M |
| 文件选择上传 | 点击按钮选择 .md 文件 | M |
| 粘贴上传 | 从剪贴板粘贴 Markdown 内容 | N |
| 同步滚动 | 编辑区和预览区滚动位置同步 | N |
| 快捷键 | 常用 Markdown 快捷键（加粗、斜体、代码块等） | N |

### 3.2 Markdown 渲染

| 功能 | 描述 | 优先级 |
|------|------|--------|
| GFM 完整支持 | 表格、删除线、任务列表、自动链接 | M |
| 代码块高亮 | rehype-highlight，支持主流语言 | M |
| 代码块行号 | 可选显示行号 | N |
| 图片渲染 | 支持本地（base64）和网络图片 | M |
| 图片自适应 | 图片宽度不超过页面，等比缩放 | M |
| 数学公式 | KaTeX 渲染行内（$...$）和块级（$$...$$）公式 | N |
| Mermaid 图表 | 流程图、序列图、甘特图等 | Future |
| 脚注 | Markdown 脚注语法支持 | N |
| Emoji | :emoji: 短代码支持 | N |

### 3.3 PDF 导出

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 一键导出 PDF | 点击按钮直接下载 PDF 文件 | M |
| 预览即所得 | 预览区样式 = 导出 PDF 样式，零差异 | M |
| 页面大小 | A4 / Letter / A3 / 自定义 | M |
| 页面方向 | 纵向 / 横向 | M |
| 页面边距 | 上/下/左/右可调，预设常用值 | M |
| 页眉 | 自定义文本、支持变量（标题、日期） | M |
| 页脚 | 自定义文本、支持变量 | M |
| 页码 | 可选位置（居中/左/右）、起始页码 | N |
| 分页控制 | CSS page-break 支持，避免标题孤悬 | M |
| 代码块跨页 | 代码块不在行中间断页 | M |
| 表格跨页 | 超长表格跨页时表头重复 | N |
| 文件名 | 自动从 h1 标题提取，可手动修改 | N |

### 3.4 主题与样式

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 预设主题 | GitHub 风格 / 学术论文 / 简历 / 简约 / 暗色 | N |
| 自定义 CSS | 用户可输入自定义 CSS 覆盖样式 | N |
| 字体选择 | 正文字体、标题字体、代码字体可配置 | N |
| 字号调节 | 正文、代码块字号可调 | N |
| 编辑器主题 | 编辑器亮色/暗色切换 | N |

### 3.5 工具功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| TOC 自动生成 | 基于标题层级生成目录页 | N |
| YAML frontmatter | 解析 frontmatter 中的导出配置（title、author、date 等） | N |
| 导出配置持久化 | localStorage 保存用户上次导出设置 | N |
| 编辑内容持久化 | localStorage 自动保存编辑内容 | N |
| 分享链接 | 将 Markdown 编码到 URL hash 中生成分享链接 | Future |
| 多标签页 | 同时编辑多个文档 | Future |

## 四、用户界面布局

```
┌──────────────────────────────────────────────────────────┐
│  Printdown           [主题▾] [设置⚙] [上传📁] [导出PDF]  │  ← 工具栏 40px
├────────────────────┬───┬─────────────────────────────────┤
│                    │ ↕ │                                 │
│   编辑区            │   │   预览区                         │
│   CodeMirror 6     │拖 │   remark 渲染                    │
│   GFM 模式          │拽 │   (所见即 PDF 所得)               │
│                    │条 │                                 │
│                    │   │                                 │
│                    │   │                                 │
├────────────────────┴───┴─────────────────────────────────┤
│  行 42, 列 8  │  UTF-8  │  Markdown  │  自动保存 ✓       │  ← 状态栏 24px
└──────────────────────────────────────────────────────────┘

导出设置面板（侧边抽屉）：
┌──────────────────────┐
│  导出设置              │
│                       │
│  页面大小  [A4    ▾]  │
│  方向    [纵向  ▾]    │
│  边距 上  [2.54cm]    │
│       下  [2.54cm]    │
│       左  [2.54cm]    │
│       右  [2.54cm]    │
│                       │
│  页眉  [{{title}}    ]│
│  页脚  [第{{page}}页 ]│
│                       │
│  [预览 PDF]  [下载PDF] │
└──────────────────────┘
```

**响应式策略**：
- 桌面端（≥1024px）：左右双栏
- 平板端（768-1023px）：可切换的标签页模式
- 手机端（<768px）：仅预览模式 + 底部浮动编辑按钮

## 五、非功能需求

| 维度 | 指标 |
|------|------|
| 首屏加载 | < 2s（Fast 3G） |
| 包体积 | 初始 < 800KB（gzip） |
| 编辑性能 | 10 万字文档无卡顿 |
| PDF 导出 | 1 万字文档 < 3s |
| 浏览器兼容 | Chrome 90+、Firefox 90+、Safari 15+、Edge 90+ |
| 移动端 | 响应式，手机可查看预览 |
| 离线 | Service Worker 缓存后完全离线可用 |
| 安全 | 零网络请求处理用户内容 |
| 隐私 | 无追踪、无分析、无第三方资源加载 |
