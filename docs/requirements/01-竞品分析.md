## 二、重点竞品详细分析

### 1. Typora（桌面端标杆）

**核心体验**：WYSIWYG 单栏编辑，编辑即预览，无左右分栏干扰。

**优势**：
- 导出 PDF 质量最高，自动生成书签（基于标题层级）
- 主题系统（CSS 即主题），灵活度极高
- 支持格式最广（PDF/Word/LaTeX/Epub/RTF 等）
- Mermaid 图表 + LaTeX 公式完整支持
- 一次性买断 $14.99，3 台设备

**劣势**：
- 无 Web 版，仅桌面端
- 付费产品，非开源
- 无协作功能

**对我们的启示**：Typora 证明了"高质量 PDF 输出"是用户最核心诉求。作为 Web 工具我们无法复刻桌面体验，但可以在导出质量上尽量逼近。

---

### 2. VS Code Markdown PDF（用户量最大）

**核心体验**：VS Code 内扩展，编辑 Markdown 后一键导出 PDF/HTML/PNG。

**优势**：
- 370 万+ 安装量，社区庞大
- 支持保存时自动导出（效率极高）
- PDF 配置丰富（页面格式、边距、页眉页脚、缩放）
- 支持 Mermaid + PlantUML 图表
- 2026 年仍在积极维护（v2.0.0 TypeScript 重写）

**劣势**：
- 依赖 Chromium，首次使用可能需下载
- 需安装 VS Code
- 样式自定义需修改配置文件，门槛高

**对我们的启示**：丰富的导出配置（页面设置、页眉页脚）是用户的高频需求。保存自动导出的思路可借鉴为"实时预览即最终效果"。

---

### 3. md-to-pdf（CLI 标杆）

**核心体验**：命令行工具 + 编程 API，Marked 解析 + Puppeteer 渲染。

**优势**：
- 架构极简（~500 行核心代码 + ~100 行 CSS）
- YAML front-matter 配置页面尺寸、边距、页眉页脚
- Watch 模式（文件变化自动重新生成）
- 支持并发批量转换
- stdin/stdout 管道操作

**劣势**：
- 依赖 Chromium（数百 MB）
- 不支持 Mermaid、数学公式渲染不稳定
- 缺少 TOC 自动生成（issue #74）
- 26 个未关闭 issue，社区维护能力有限

**对我们的启示**：front-matter 配置思路可借鉴——让用户在 Markdown 头部声明导出配置。极简架构值得学习。

---

### 4. Dillinger（Web 端参考）

**核心体验**：在线 Markdown 编辑器，Monaco 编辑器 + 实时预览。

**优势**：
- 零门槛，打开即用
- 支持 5 种云存储同步（GitHub/Dropbox/Google Drive/OneDrive/Bitbucket）
- Zen 模式、Vim/Emacs 键位
- 离线模式可用

**劣势**：
- PDF 导出排版自定义有限
- 不支持 LaTeX 公式、Mermaid 图表
- 更新不活跃

**对我们的启示**：零安装 + 离线可用是 Web 工具的核心卖点。云同步是加分项但不应该是初期重点。

---

### 5. Pandoc（学术标杆）

**核心体验**：通用文档格式转换器，数十种格式互转。

**优势**：
- 格式支持最广泛，20 年历史
- 学术论文首选（完整引用/参考文献系统）
- 多种 PDF 引擎可选（LaTeX/WeasyPrint/Prince 等）
- Lua 过滤器 + 模板系统

**劣势**：
- 学习曲线极陡
- PDF 输出需额外安装 LaTeX（数 GB）
- 无图形界面
- 中文字体需额外配置

**对我们的启示**：Pandoc 不直接竞争，但它的学术功能（引用、公式、脚注）代表了用户对专业文档的期望上限。

## 四、竞争定位分析

```
                        安装门槛高
                            |
                    Pandoc  |  Typora
                  VS Code   |
                  md-to-pdf |
                            |
     功能弱  ----------------+----------------  功能强
                            |
                  markdown- |
                  pdf(废弃) |
                            |
                   Dillinger|  ★ 我们的目标位置
                   StackEdit|  (零安装 + 功能强 + 离线)
                            |
                        安装门槛低
```

**我们的核心定位**：在"零安装 + 离线"的象限内，做到功能最强。
这正是当前市场空白——Dillinger/StackEdit 在这个象限但功能弱，Typora/VS Code 功能强但需安装。

## 五、差异化策略

1. **零安装 + 离线**：唯一的"浏览器打开即用、完全本地处理"的高质量 MD→PDF 工具
2. **预览即所得**：所见即所得的 PDF 预览，消除"预览和导出不一致"的痛点
3. **中文字体优先**：内置高质量中文字体栈，开箱即用（多数竞品需手动配置）
4. **主题模板市场**：预设多种场景模板（简历/论文/技术文档），一键切换
5. **完全免费开源**：MIT 协议，社区驱动
